# sengokudynasty-villager-calc

Try it here: https://piko1250.github.io/sengokudynasty-villager-calc/

## About (EN)

A production calculator for Sengoku Dynasty. Enter your worker's level,
perk, tool production modifier, and specialization bonus to estimate each
facility's daily output. Estimates only — actual results may vary.

## About (JP)

Sengoku Dynastyの生産量計算ツールです。労働者レベル・パーク・道具生産調整・
専門ボーナスを入力すると、各施設の一日の生産量を推定できます。あくまで
推定値なので、実際の結果とは異なる場合があります。
